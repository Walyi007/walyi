## Déployer sur GitHub Pages

1. Créer le repo sur GitHub :
   - Nom : ``
   - Public
   - Sans README

2. Pousser :
```powershell
git remote add origin https://github.com/Walyi007/walyi.git
git branch -M main
git push -u origin main
```

3. Activer Pages :
   - Settings → Pages → Source : `main` → Save
   - URL : `https://Walyi007.github.io/walyi`
